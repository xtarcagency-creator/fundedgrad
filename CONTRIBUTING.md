# Contributing

Most fixes are edits to `AGENTS.md`. Small, focused pull requests are best.

## Reporting a problem

Open an issue with:
- which CLI and model you used,
- the program URL,
- what the agent wrote vs what the official page says.

**Don't paste your profile, tracker, SOP, transcript or any personal
details into an issue.** Issues are public. Redact names, IDs, grades and
nationality unless they're needed to show the bug, and then generalise
("a South Asian applicant with a 3.4/4 GPA").

## Rules for changes

- Keep the hard rules in `AGENTS.md` (no invented facts, never submit).
- Sources must be official pages, not aggregators or referral links.
- Never commit anything from `data/`.
- Add a line to `docs/CHANGELOG.md`; move items in `docs/ROADMAP.md`.
- Big direction changes: add an entry to `docs/DECISIONS.md` with the reason.
